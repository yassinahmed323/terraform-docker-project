# Terraform Docker Project

## Project Overview
This is my IT 293 quarter project at Bellevue College.

The goal is to use Terraform Infrastructure as Code (IaC)
to create and manage Docker containers.

## Technologies
- Terraform
- Docker
- GitHub
- GitHub Codespaces
- Nginx

## Project Goals
- Learn how Terraform manages infrastructure.
- Create Docker containers using Terraform.
- Configure and test an Nginx web server.
- Practice version control using GitHub.
- Document the setup and results.

Initial repository setup in progress.
